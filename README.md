# Lőcsei Szalon

Modern, reszponzív weboldal a budapesti Lőcsei Szalon számára.

## Tartalom
- Fodrászat – Andi
- Kozmetika
- Manikűr & Pedikűr – Marcsi
- Masszázs – Jutka
- Galéria
- Kapcsolat

Az első verzió külső képeket használ a vizuális helykitöltéshez. Andi és Marcsi eredeti munkafotói a következő frissítésben kerülnek a galériába.
